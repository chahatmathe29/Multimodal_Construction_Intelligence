# Multimodal Construction Intelligence Platform
SmartBridge / Skill Wallet Capstone Project 1 (Platform ID: 6ac4c98d1dcde6d7857c1642)

## Features
- **Epic 2: PPE Safety Auditing**: Detects PPE compliance (helmets, vests, safety harnesses) under OSHA / IS 456.
- **Epic 2: Crack Structural Diagnostics**: Evaluates concrete defect types and remediation.
- **Epic 3: Planning & Valuation**: Estimates construction budget, steel/cement requirements, and asset valuation in INR.
- **Epic 5: Weather Advisory & Site Chatbot**: Dynamic weather alert protocols and an interactive engineering assistant.

## Setup & Deployment
1. Install dependencies: `pip install -r requirements.txt`
2. Run app: `streamlit run app.py`
3. Deploy to Streamlit Community Cloud (share.streamlit.io).
